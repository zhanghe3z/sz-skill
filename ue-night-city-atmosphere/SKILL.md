# UE 科幻夜景城市：按教程顺序操作

在已经搭建好的城市中，完成偏俯视镜头下的夜景基本氛围。默认目标：低强度环境光、雾中远景剪影、发光城市背景和统一的青蓝冷色调。用户另有风格或镜头要求时，以用户要求为准。

以下步骤按录屏整理；节点命名和操作检查点为便于执行而补充。教程没有提供通用参数表或正式评分权重。需要核对来源时，读取 [教程证据与验收标准](references/tutorial-evidence.md)。执行本流程不依赖原录屏存在。

## 开始前

1. 确认目标 UE 工程、关卡和拍摄相机；优先从已打开的工程、当前视口和用户提供的路径识别。目标有歧义时，先明确目标再修改。
2. 确认城市主体已搭建，找到 Directional Light、Exponential Height Fog 和后期体积 Post Process Volume。缺少对象时在目标关卡补齐；不要重建整座城市。
3. 找到可用的夜景城市背景图和 LUT 资源。背景应与镜头俯视角度、建筑尺度及冷色调相近，并露出少量天空。录屏里的照片与 LUT 不随此 Skill 提供。缺少背景时可先完成步骤 1–3，随后请求资源；缺少 LUT 时可先完成步骤 1–7，随后请求资源。用户授权其他调色方式后才替换步骤 8，并明确记录替代方式。
4. 建立相同相机、相同视口尺寸下的初始画面，记录将修改对象的原始参数。沿用工程已有目录和命名规范。
5. 使用当前可用的 UE 控制接口操作；已有的编辑器 API/插件优先，否则使用 UI。UI 操作以当前界面和可访问控件为依据，不照搬录屏坐标。接口与属性名必须能在当前环境中确认；不要虚构 Unreal API 或宣称执行了未执行的修改。

执行授权来自当前用户请求；仅创建或阅读此 Skill 不代表要修改 UE 工程。没有控制 UE 的工具时，输出当前步骤的具体操作和检查点，明确标记尚未执行。

## 执行规则

- 按步骤 1–10 推进；已有步骤达标时先核验，再标记为已满足，不强行重做。
- 每个步骤都包含操作和检查点。检查后才进入下一步；步骤 3 的雾气效果先做初检，在步骤 7 添加背景后复检。
- 参数以当前画面为准，一次调整一类因素并与调整前对比。不要将未知数值补成教程参数，也不要把示例参数当成通用常量。
- 记录对象/资产路径、实际参数改动、检查结果和下一步。缺少资源或访问能力时停在受影响步骤，保留已完成工作。
- 对失败操作先读错误或查看当前 UI 再修复；同一操作连续失败两次且没有新证据时，停止该操作并报告具体阻塞。

## 步骤 1：整理对象，锁定评价视角

操作：在 Outliner 中选中上一阶段的小型建筑，排除相机、雾和其他非建筑对象；按工程惯例归入文件夹。教程示例名称为 `SmallBuild`。材质目录中准备 `Sky` 子目录。回到目标相机视图，后续调节以此镜头为准。

检查：对象分组正确，相机和雾没有被误移动；前后对比来自同一镜头。避免切换自由视口后用不同视角判断效果。

## 步骤 2：降低定向光，建立夜景光感

操作：选中 Directional Light，逐步降低光照强度。观察屋顶受光、建筑形体和小范围反射；保留微弱的光影信息。让广告牌、射灯等已有局部光源承担主要高亮。

检查：城市整体呈夜景，屋顶和建筑仍有微弱可读性；环境光没有把全城均匀照亮。当前课只确立基本氛围，不扩展成下一课的重点区域灯光制作。

## 步骤 3：提高雾气浓度，初步拉开层次

操作：选中 Exponential Height Fog，适度提高雾密度（在当前版本界面确认 Fog Density）。重点观察远景建筑细节如何衰减，保留近景与远景的区别。记录雾参数，暂定当前效果。

检查：远景更朦胧，接近剪影；近景仍有结构信息，整个画面没有变成均匀的灰幕。此时不要求远景轮廓最终达标，背景发光会在步骤 7 改善轮廓可读性。

## 步骤 4：选择匹配镜头的夜景城市背景

操作：检查候选图的视角、天空占比、色调和建筑光点。对本教程的偏俯视镜头，优先选含少量天空的夜景城市图；夜景云层信息应微弱。确认选图与场景尺度协调，再导入工程或使用已有纹理。

检查：背景视角与相机相近，色调与场景兼容；城市灯光细节能丰富远景。不要为了遵循示例而忽略用户镜头的实际天空占比。

## 步骤 5：制作可替换、可调亮度的发光背景材质

操作：在材质目录中创建或复用专用于背景的材质，示例名为 `M_Sky`。使用以下节点关系：

```text
城市背景 Texture Sample Parameter 2D 的 RGB
    × Scalar Parameter（背景发光强度）
    → 材质的 Emissive Color
```

将纹理暴露为参数以便替换，并将发光强度暴露为标量参数以便材质实例调节。参数名可采用 `CityTexture` 和 `EmissiveStrength`，这是本 Skill 的建议命名。完成编译/应用，再创建材质实例，示例名为 `MI_Sky`。

教程还取消了材质的投射光追阴影选项。仅在当前界面确认存在对应属性（如 Cast Ray Traced Shadows）且可编辑后修改；当前版本未提供该选项时记录差异，不阻塞背景材质制作。不要擅自加入录屏未要求的材质模式或渲染系统切换。

检查：材质正常编译、城市图像正确显示，纹理和强度可通过实例调整；没有默认棋盘格或资产引用错误。

## 步骤 6：摆放背景平面，匹配位置与比例

操作：添加或复用背景 Plane，将背景材质实例赋给它。沿目标相机看向城市的方向，把平面放在城市远景的后方，朝向相机，调整位置、旋转和缩放。可以另开自由视口定位，但以目标相机画面验收。需要覆盖更大范围时拼接多个平面。

检查：背景覆盖镜头所需范围，没有可见空洞或平面边缘；背景建筑与三维城市的尺度和透视协调。避免只将一张图过度拉大，造成建筑比例失真。

## 步骤 7：处理重复地标，分区调亮度并复检层次

操作：检查拼接图的重复特征。对显眼地标，利用位置调整和前景建筑遮挡减少重复。需要不同亮度的平面使用独立材质实例，微调各自发光强度，形成细微变化；不要直接改共享母材质影响所有平面。对比背景显示/隐藏的效果，再确认最终开启。

检查：没有突兀的重复地标和拼接痕迹；背景增加光点细节，与场景色调融合，并衬出雾中远景建筑轮廓，使空间延伸更远。若雾遮住所有轮廓，返回步骤 3 小幅修正后，再核验本步骤；避免把远景恢复成与近景一样清晰。

## 步骤 8：通过 LUT 统一青蓝色调

操作：选中影响目标相机的 Post Process Volume，在当前版本中查找 Color Grading LUT，赋予已确认可用的 LUT 资源，调节 Color Grading LUT Intensity。若使用相机后期设置或其他等效载体，先确认其实际影响镜头，并记录载体差异。比较应用前后和不同强度，适当减弱过浓的滤镜效果。

检查：画面呈青蓝冷色调，城市与背景更融合；局部亮点仍能辨认，滤镜没有吞掉层次。青蓝色是本例的风格目标，不是所有夜景的强制要求。

## 步骤 9：调整曝光与明暗曲线，减少灰蒙感

操作：在已确认影响镜头的后期设置中查找曝光参数（教程示范 Exposure Compensation），适度提高曝光后观察。若仍发灰，查找 Film 的 Slope 并小幅调整，比较暗部、建筑轮廓和高亮。教程口述称其为“灰度”调整，画面实际操作的是 Film Slope；不要将它理解为转成灰度图或降低饱和度。

检查：画面明暗区别更清楚，仍然保持夜景基调；避免提亮后环境光感过强、暗部失去结构或背景高亮抢走注意力。不要同时改曝光、LUT 和雾气而无法判断变化来源。

## 步骤 10：最终验收并保存

在目标相机中核验六项：夜景光照、雾气与空间层次、背景视角匹配、拼接与尺度、色调统一、曝光与明暗对比。每项记录“满足 / 待调整”及可观察的理由；详细判据见 [验收标准](references/tutorial-evidence.md#验收标准)。不要伪造截图或检查结果。

保存此次修改的关卡、材质、实例和后期设置，确认保存成功。向用户报告完成步骤、修改对象/资产路径、关键参数前后值、画面对比及遗留项。保存后完成本教程范围；窗户材质、HUD、广告牌制作、街道流光和动画属于后续课程，只有用户另行要求才继续。
